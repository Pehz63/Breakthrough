# six category identities exist and are certified together.

# tracks.txt, and a line containing a `.` is rejected as a pasted full id.

# (qs, noOrd, margin=, deep=4), the deep=8/nodes=2m reference oracle, rand@1,
# the greedy and smart controls and the off gaz checkpoints stay as explicit
# lines in ranking/roster.txt, where they are study data rather than entrants.
# Before 2026-09-07 they were entrants by accident: category membership was
# decided by "the id mentions nodes= somewhere", which put 17 ablation rows in
# the openless x node title race.
