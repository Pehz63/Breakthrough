# Curated GUI agents: role | name | canonical id | description
#
# The GUI's "Presets" library tab lists every line. The roles easy / medium /
# hard pick the simple mode's difficulties (the web build's only mode), and
# watch_white / watch_black pick its "Watch" matchup. The web build bundles the
# model file of every learned(model=N,...) agent named here from the byte-exact
# copies in gui/web_models/. After changing a line, run
# tools\web_preloads.ps1 -Sync and commit the copies.
#
# Ids are canonical: an id with a stale module version fails to load and the GUI
# reports it. Elo figures quoted below are from ranking/standings.tsv's fit of
# 2026-09-06, all on the ab(deep=6,tt,ord,nodes=200k)@3 head. Re-read standings
# before quoting them anywhere else.

easy        | Easy        | ab(deep=6,tt,ord,nodes=200k)@3.learned(model=10,fead67b7,weight_merge,lin,shape=129-1)@1.dil(prob=20)@1 | 20% of its moves are random (dil20 x node champion, 660 in the 2026-09-06 fit)
medium      | Medium      | ab(deep=6,tt,ord,nodes=200k)@3.learned(model=10,fead67b7,weight_merge,lin,shape=129-1)@1.opener(rand,moves=8)@1 | first 8 of its own moves random, then full strength (883 in the 2026-09-06 fit)
hard        | Hard        | ab(deep=6,tt,ord,nodes=200k)@3.learned(model=169,4975683c,tdleaf_self,lin,shape=129-1)@1 | the strongest rated agent, deterministic (openless x node co-champion, 1227 in the 2026-09-06 fit)
watch_white | Watch White | ab(deep=6,tt,ord,nodes=200k)@3.learned(model=10,fead67b7,weight_merge,lin,shape=129-1)@1.opener(rand,moves=8)@1 | random first 8 moves so every game differs (883 in the 2026-09-06 fit)
watch_black | Watch Black | ab(deep=6,tt,ord,nodes=200k)@3.learned(model=76,ef183148,position_elo,lin,mu_shape=129-1,sigma_shape=129-1)@1.opener(rand,moves=8)@1 | opener8 x node champion (880 in the 2026-09-06 fit)
preset      | Classic d8 (legacy GUI default) | ab(deep=8)@3.classic(chip=100)@2 | the GUI's historical default opponent, unbudgeted depth 8 over the chip counter
